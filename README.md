NLP Spam Message Detector

Project Overview

This project uses Natural Language Processing (NLP) and Machine Learning to classify text messages as Spam or Ham (Not Spam).

Features

- Detects spam and normal messages.
- Converts text into numerical features using TF-IDF.
- Uses Linear Support Vector Machine (SVM).
- Provides an interactive interface using Streamlit.
- Compares multiple machine learning algorithms.

Technologies Used

- Python
- NLP
- Pandas
- Scikit-learn
- TF-IDF
- Linear SVM
- Streamlit
- Joblib

Model Performance

Linear SVM achieved 99.03% accuracy on the test set in this project.

How to Run

1. Install the required libraries:
   "pip install -r requirements.txt"

2. Start the application:
   "python -m streamlit run app.py"

Project Goal

To build an NLP-based application that identifies spam messages and distinguishes them from normal messages.
